# 사진 넣는 곳

## 권장 규격

| 용도 | 파일명 | 크기 | 비고 |
|---|---|---|---|
| 카톡·SNS 링크 미리보기 | `og.jpg` | 1200 × 630 | `index.html` 상단 `og:image` 주석 해제 |
| 히어로 배경 (선택) | `hero.jpg` | 가로 2000px 내외 | 현재는 도면 SVG를 쓰고 있음 |
| 차량 사진 | `car-2025.jpg` 등 | 가로 1600px 내외 | 연도를 파일명에 |
| 후원사 로고 | `sponsors/<회사>.svg` | SVG 우선, 없으면 PNG 투명배경 | 다크모드에서도 보이는지 확인 |

## 올리기 전에

- **용량을 줄이세요.** 원본 20MB짜리 JPG를 그대로 올리면 폰에서 안 열립니다.
  가로 1600px 이하, 파일당 300KB 이하를 목표로 하세요.
  [squoosh.app](https://squoosh.app) 에 끌어다 놓으면 됩니다.
- 사람 얼굴이 크게 나온 사진은 **본인 동의를 받고** 올리세요.
- 대회 사진은 공개 동의와 사용 권한을 확인한 선별본만 이 저장소에 추가하세요.

## HTML에 넣는 법

```html
<img src="assets/img/car-2025.jpg"
     alt="2025년 대회 차량 ARTEMIS GT 주행 장면"
     width="1600" height="900" loading="lazy">
```

`alt` 는 화면을 못 보는 사람과 검색엔진이 읽습니다. 사진에 **무엇이 찍혀 있는지** 적으세요.
`width`/`height` 를 적어두면 사진이 늦게 떠도 레이아웃이 안 흔들립니다.
